# poidem-engine

Рилсы «Пойдём» в Remotion: наклейки, отсчёт, свайп «Хочу», концовка бренда.

```bash
pnpm install
cp .env.example .env
pnpm run smoke                      # пробный рендер в out/smoke
pnpm run render -- <папка ролика>   # из poidem-content/reels/
```

Правила и структура: `AGENTS.md`, контракт с vault: `docs/contract.md`.
