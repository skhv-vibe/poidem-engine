# Контракт с poidem-content

Меняется только с обеих сторон одновременно: схема здесь, шаблон и плейбук `order` в vault.

## Вход

`$POIDEM_CONTENT/reels/<ролик>/promo.yaml` по схеме `schema/promo.schema.json`. Пути к медиа указываются от корня `poidem-content`, для примеров движка — от папки заказа.

| Поле | Что |
|---|---|
| `format` | Шаблон ролика: `listicle` (подборка) или `spot` (одно место) |
| `hook.text` | Хук-наклейка, до 60 знаков. Перенос строки вручную — `\n` |
| `hook.clip` | Свой клип под хук (2 с до мест). Без него хук лежит поверх первого места |
| `items[]` | Места в порядке показа, номер считается сам (N → 1). У места `name`, необязательный `district`, `clips[]` |
| `clips[].in/out` | Отрезок клипа в секундах. Время места делится между клипами поровну |
| `demo` | Запись приложения после свайпа «Хочу». Без `out` длится 3 с |
| `music` | Трек, затухает в последние 20 кадров |
| `end.line` | Строка под логотипом в концовке |
| `shots[]` | `spot`: кадры места встык, у каждого `src`, `in`, `dur` (секунды в ролике) |
| `app` | `spot`: макет ленты, `card` и `next` (`photo`, `title`, `meta`, `line`), `dur`, `swipe_at` — секунда нажатия «Хочу» от начала сцены |
| `voice` | `text`, `voice_id`: закадр. `pnpm run voice` кладёт рядом с заказом `voice.mp3` и `voice.json`, по ним идут субтитры |
| `requests[]` | Чего не хватило в движке: попадает в отчёт как предупреждение |

## Выход

Движок пишет в папку ролика только это:
- `render/reel.mp4` (1080×1920, 30 fps, H.264), `render/contact.png` (2 кадра в секунду), `render/frames/*.png` (хук, каждое место, демо, концовка);
- `render-report.md` со `status: ok | warnings | failed`.

Статусы ролика движок не трогает.
